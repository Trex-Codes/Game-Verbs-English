# Game-Verbs-English 🎮

A simple, interactive web-based game designed to help you practice and master English verbs. 

![img](https://github.com/Trex-Codes/Game-Verbs-English/blob/master/Assets/F1.png)

![img](https://github.com/Trex-Codes/Game-Verbs-English/blob/master/Assets/F2.png)

## 🚀 Features
- Minimalist, distraction-free UI.
- Quick and effective English verb practice.
- Built with pure HTML, CSS, and JavaScript (No extra installations required).

## 🕹️ How to Play
1. Download or clone this repository to your computer.
2. Open the `Start.html` file in any modern web browser.
3. Start mastering your verbs!

## 🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
